# Sponsoring

quickadd-macos-menubar is free and MIT licensed. One person maintains it in their spare time.

If it saves you time, you can support the work:

- [Sponsor shortcuts on GitHub](https://github.com/sponsors/shortcuts)

Sponsoring is optional. It does not buy priority on issues or features.

Other ways to help cost nothing:

- Star the repository.
- Report a bug with a clear way to reproduce it.
- Send a pull request. See [CONTRIBUTING.md](./CONTRIBUTING.md).
